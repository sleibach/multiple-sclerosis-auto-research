# External Knowledge Intake Templates

Templates in this directory are not live external records. They exist to make
future intake consistent with V47 epistemic segregation.

Rules:

- copy a template to a live record path only after filling every mandatory
  provenance field;
- keep external-verifiable claims marked `NOT_PROJECT_GROUNDED` until they are
  tested by a separate grounded project analysis;
- never cite a queued external-verifiable claim as project evidence.
