# V50 GSE235357 / S-EPMC10360655 Handoff

Status: source-route handoff and no-recount guardrail. This artifact prevents a
known source route from being counted twice. It is not biological evidence, does
not import expression data, and does not change any grounded treatment-response
finding.

## One-Line Rule

`S-EPMC10360655`, PMID `37483622`, DOI `10.3389/fimmu.2023.1209923`, and
`GSE235357` are the same Sánchez-Sanz 2023 DMF PBMC response source family for
V50 accounting. They must not be counted as a new independent validation cohort
unless a genuinely new same-definition package or label/access event appears and
passes the V50 source-hit template.

| lane | class | what it means |

| Sánchez-Sanz / GSE235357 external record | `external-unverifiable` | `knowledge_external/records/dmf_pbmc_response_signature_sanchez_sanz_2023.json` stores a sourced external claim and source metadata. It is not project evidence. |

## Why It Is Not Independent

| item | status | reason |
|---|---|---|
| `GSE235357` | already represented in grounded/local treatment-response artifacts | The project already treated this as part of the existing V22/V23/V28/V32 treatment-response evidence chain. Re-finding it through another API is not new validation. |
| `S-EPMC10360655` | duplicate/alternate metadata route | The V50 BioStudies search identified it as the Sánchez-Sanz 2023 DMF PBMC response source family. The source-hit independence QA assigns it to canonical cluster `gse235357_sanchez_sanz_dmf_pbmc_response`. |
| external Sánchez-Sanz record | context/source metadata only | The external record is useful corroborating context, but its `NOT_PROJECT_GROUNDED` marker prevents it from being used as project evidence. |

## Reopen Trigger

Only reopen this source family if one of the following appears:

1. A new sample-level package, response-label file, or access-terms update that
   was not part of the already-used local GSE235357 route.
2. A concrete field mapping that proves the package satisfies the frozen V42 /
   V50 same-definition gates for an allowed validation or future-grounding run.
3. A genuinely independent cohort from a different source family, not a
   rediscovery of Sánchez-Sanz 2023 through a second metadata API.

If reopened, route it through
`knowledge_external/templates/V50_NON_OPENGWAS_SOURCE_HIT_REVIEW_TEMPLATE.md`
and the no-recount checker before any source count is changed.

## Safe Interpretation

The correct current interpretation is:

- `GSE235357` remains part of the already-known project treatment-response
  evidence chain.
- `S-EPMC10360655` is a useful alternate metadata route to that known source
  family.
- Neither `S-EPMC10360655` nor the external Sánchez-Sanz record adds an
  independent validation cohort count.
- This is a source-accounting decision only; it does not strengthen or weaken
  the biological result.
