# HYP_V6_012 - TYK2 Pregnancy / Postpartum IFN-Source Biomarker

Status: alive  
Tier: Tier -1  
Opened: 2026-05-28 20:51 CEST

## Hypothesis

TYK2/JAK-STAT biology may be useful as a pregnancy/postpartum IFN-source
biomarker or combination-selection axis even if TYK2 allosteric inhibition does
not currently pass Tier 0 as an MS therapeutic target.

## Opening Evidence

V5 TYK2 demotion held because no MS/subgroup anchor existed beyond broad
JAK/IFN biology. V5 pregnancy work, however, preserved an ISG-dominant MS
month-9 signal and cross-disease postpartum APC/IFN kinetics. This creates a
Tier -1 biomarker/refinement route.

## First Independent Checks

- Score TYK2/JAK-STAT downstream modules in pregnancy/postpartum datasets.
- Test whether TYK2-like IFN source patterns separate MS, RA, and SLE pregnancy
  kinetics better than broad IFN/APC scores.
