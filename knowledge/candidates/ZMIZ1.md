# ZMIZ1

Status: robust decoupling finding; not an intervention lead  
Last updated: 2026-06-06  
Primary evidence file: `../../GENETICS_EQTL_WORKUP_V16.md`

## Current Verdict

`ZMIZ1` is a confirmed opposite-direction MS-Crohn decoupling locus. It should
not be used as a Crohn-to-MS transfer target.

## Evidence

- V14 bounded SuSiE-coloc supported the MS-Crohn chr10 shared locus.
- V16 eQTLGen evidence showed all four shared credible-set variants increase
  `ZMIZ1` expression.
- The same expression-increasing alleles are MS-risk and Crohn-protective.

## Limits

- Formal full QTL colocalization and perturbation validation remain useful for a
  publication-grade writeup.
- `ZMIZ1` is not directly druggable in the current evidence base.

## Next Required Test

Preserve as a transfer-validity decoupling finding. Only revisit for formal
QTL-coloc hardening or perturbation-based mechanism, not for therapeutic
repositioning.
