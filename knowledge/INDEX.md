# Knowledge Index

Canonical V4 knowledge lives here.

## Main Sections

- `candidates/`: one file per candidate or candidate family.
- `dimensions/`: one file or section per evidence dimension.
- `mechanisms/`: mechanism hypotheses independent of a single target.
- `datasets/`: dataset registry and access notes.
- `tools/`: tool, model, and environment registry.
- `decisions/`: append-only numbered decision records.

## Required Read Order For Future Agents

## V4 Operating Rule

Before launching a candidate analysis, check:

- the candidate file under `candidates/`,
- the decision log under `decisions/`,
- the archive index for V3 wave outputs,
- and, when provisioned, the local RAG index.
