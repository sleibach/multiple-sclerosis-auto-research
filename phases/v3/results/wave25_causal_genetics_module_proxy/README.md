This audit intentionally does **not** claim causality. It integrates local mapped-gene/locus genetics, GTEx eQTL availability, cross-disease module evidence, residualization survival, foundation/perturbation signals, and modality blockers to decide whether any candidate can support a target-resolved genetic claim in this run.

Promotion requires proper SNP-level colocalization or MR plus module-state perturbation support. The current local inputs do not satisfy that requirement.
