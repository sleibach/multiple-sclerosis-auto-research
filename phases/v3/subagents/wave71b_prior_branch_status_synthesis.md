## Executive Memory

The V3 run repeatedly recovered a real cross-autoimmune inflammatory
myeloid/APC state: lipid/lysosomal stress, antigen processing, HLA-II/CD74,
MIF/CD74, complement/phagocytosis, and Fc/ROS/inhibitory-resolution readouts.
That state has not yielded a promotable intervention point. The dominant
failure pattern is proxy satisficing: state markers, broad immune genetics,
anti-inflammatory pharmacodynamics, and foundation-model embedding shifts keep
looking like targets until direction, perturbation, safety, modality, and prior
art are enforced.

Current operating rule: do not reopen a branch from expression recurrence,
module coupling, broad mapped-gene genetics, ChEMBL existence, or model-only
support. Reopen only with target-resolved causal direction plus disease-relevant
perturbation and guardrails, or with a clearly orthogonal modality that answers
a previously unsolved blocker.

## Branches Not Fully Falsified, But Not Claims

The following are analysis-worthy only because their decisive blockers were
missing-data or direction tests, not because they are close to promotion.
Exclude Fc/ROS variants from this list by instruction.

1. `MFGE8`/debris-opsonin ex vivo repair: worth only as an assay program for
   myelin-debris uptake, bystander phagoptosis, cytokines, and integrin/RGD
   dependence.
2. `GPR65` acidic-tissue GPCR restoration: worth only if non-IBD/MS
   fine-mapping and agonist/PAM human disease-cell data can be obtained.
3. `PTPN2`/tolerance-restoration genetics: worth only as a target-resolved
   direction and modality problem; no inhibitor-based autoimmunity claim.
4. FADS/lipid-desaturation stratification: worth only with coloc/MR,
   genotype-stratified lipidomics, and direct perturbation; locus-level
   mapped-gene evidence is insufficient.
5. Orthogonal proteomics/lipidomics of the lipid/lysosomal state: worth as a
   mechanism-discovery/readout strategy, especially tissue/CSF/cell-resolved
   data, not as another single-gene expression rerank.

  `PI3K`, checkpoint/costimulation, `LILRB2`, or `INPP5D` reopener from the
  current local evidence set.

## Practical Reopen Standard

A future branch must state all four before consuming major analysis time:

1. What prior blocker is being answered, with source file.
2. What new evidence channel was unavailable or unused before.
3. What direction of intervention is proposed and why it matches causal risk.
4. What negative result would permanently close the branch.

If a proposed branch cannot answer those four, it is probably another pass over
a known dead end.
