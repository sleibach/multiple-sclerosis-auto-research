# V6 Tier -1 Exploration Rulebook

Last updated: 2026-05-28 20:51 CEST

## Purpose

Tier -1 exists to generate hypotheses from weak, confounded, negative, or
mechanistically ambiguous observations. It is not a therapeutic-claim tier.
Applying Tier 0-4 evidentiary discipline at Tier -1 is a methodology error.

## Entry Criteria

A pattern enters Tier -1 when any one condition is met:

- uncorrected p `< 0.10`;
- absolute Hedges g `> 0.5`;
- directional consistency across more than half of independent measurements;
- a Tier 0+ negative result reveals a biologically plausible failure mode;
- a covariate absorbs a signal and the covariate itself has disease biology;
- a subagent or data-mining pass surfaces one support channel for a concrete
  biological pattern.

## Discipline

- Loose statistics are allowed. Tier -1 is for opening hypotheses, not claiming
  intervention-ready biology.
- Confounders are productive. If a signal disappears after adjustment, the
  adjusted-out variable becomes a hypothesis if biologically plausible.
- Negative results must refine. A Tier -1 closure should produce three to five
  branch hypotheses unless the branch has already generated a Tier 0 promotion.
- Prior art is ignored at entry. It is checked only at Tier -1 to Tier 0
  promotion.
- Each Tier -1 hypothesis must be specific enough to state: condition, cell or
  compartment, direction, expected readout, and first independent check.

## Promotion To Tier 0

Promote when all are true:

- hypothesis is concrete enough for a Tier 0 test;
- at least one independent support channel beyond the opening pattern exists;
- V4 prior-art standard leaves a specifiable contribution;
- no obvious fatal modality or biology contradiction appears.

## Closure

Close only when:

- refinement branches have been tested under Tier -1 standards; and
- the hypothesis either produced a Tier 0 promotion or the refinement tree is
  exhausted.

## V6 Guardrail Examples

- `CD74` collapsing into broad APC/size covariates does not only demote
  MIF/CD74. It opens upstream APC-controller and cell-state-size hypotheses.
- `GSE17410` MS pregnancy IFN/APC collapsing after hematologic composition
  adjustment does not only falsify a PBMC IFN/APC mechanism. It opens
  erythroid, platelet, neutrophil, and pDC-source hypotheses.
- Uniform Tier 0 demotions across CTSS, TYK2, TREM2, LTA4H, and related targets
  are suspect at Tier -1. Each demotion must be mined for a narrower mechanism,
  subgroup, modality, or dimension where the negative result is informative.
