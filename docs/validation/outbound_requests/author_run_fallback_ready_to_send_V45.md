# Author-Run Frozen Harness Fallback Request: Ready-To-Send Draft V45

Status: unsent fallback draft. Send only after the medical team approves the
external contact and the original data-transfer request is blocked or declined.
Save the exact sent text separately after sending.

Use case: a cohort owner cannot transfer individual-level expression or clinical
data, but may be willing to run the frozen validation harness locally and return
non-sensitive aggregate outputs.

Primary packet index:

`docs/validation/AUTHOR_RUN_PACKET_BUNDLE_INDEX_V45.md`

Minimum returned outputs:

`docs/validation/AUTHOR_RUN_MINIMUM_OUTPUT_SPEC_V45.md`

## Subject

```text
Fallback option: local run of frozen MS treatment-response validation harness
```

## Email Body

```text
Dear [Dr. / Prof. / Team],

Thank you for considering our request for the treatment-response cohort data.
If individual-level expression or clinical data cannot leave your institution,
we can use a lower-disclosure fallback: your team runs the frozen validation
harness locally and returns only non-sensitive aggregate outputs.

The analysis plan was frozen before data access. The locked rule, module genes,
score sign, early-treatment feature, thresholds, and interpretation grid must
not be changed. This is important because the validation is only meaningful if
it is run mechanically, without fitting or tuning to your cohort.

The local run would require your team to:

1. prepare local expression and metadata files using the provided schemas;
2. freeze the outcome-label dictionary locally before scoring;
3. run the module-coverage precheck;
4. run the frozen validation harness exactly as supplied;
5. return only the aggregate output files listed in the minimum-output
   specification.

The aggregate output package should include, where generated by the harness:

- validation_summary.json
- sample_attrition.tsv
- gene_mapping_coverage.tsv
- locked_rule_metrics.tsv
- confounder_adjustment_metrics.tsv
- joint_confounder_metrics.tsv
- batch_diagnostic_metrics.tsv
- exact command line, software/version notes, and hash/integrity confirmation

Please do not return raw expression matrices, individual-level clinical labels,
private sample IDs, signed/private agreements, or any credentials unless your
data-use terms explicitly permit transfer. The aggregate output package is
intended to be sufficient to classify the result under the pre-specified outcome
grid without moving sensitive individual-level data.

We can send the complete non-sensitive packet containing the locked rule,
preregistration, schemas, scripts, hash baseline, redaction checklist, and report
template. If helpful, we can also answer implementation questions, but any
change to modules, endpoint orientation, timepoint selection, thresholds, or
pass/fail criteria would make the run exploratory rather than a validation.

Kind regards,

[Name / affiliation]
```
