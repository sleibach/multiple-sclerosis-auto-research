# Module Coverage Precheck V45

Purpose: catch missing frozen module genes in a received expression matrix before
running the full V42/V45 validation harness.

This is an additive readiness guard. It does not change `LOCKED_RULE_V22.md`,
does not compute module scores, does not read outcomes, and does not replace the
frozen validation harness.

## Command

For a quarantined received matrix:

```bash
.venv/bin/python scripts/v45_module_coverage_precheck.py check \
  --expression data/quarantine/<cohort>/processed/expression.tsv \
  --outdir analysis/module_coverage_precheck/<cohort> \
  --fail-on-error
```

For the synthetic software check:

```bash
.venv/bin/python scripts/v45_module_coverage_precheck.py synthetic-check \
  --outdir analysis/v45_module_coverage_precheck
```

## Inputs

The expression file is expected to be tab-delimited with gene identifiers in the
first column and samples in subsequent columns. The precheck reads only the first
column. It ignores expression values except for confirming that the file can be
parsed as a matrix.

Gene identifiers are normalized using the same `normalize_gene_id` helper used
by `scripts/v42_gafson_validation_harness.py`.

## Frozen Gene Sets

The utility imports the frozen module definitions from the V42 harness:

- primary locked-rule components: `IFN_APC`, `HLAII`, `RECEPTOR`
- all V42/V32 confounder and diagnostic modules via `ALL_MODULES`

The primary gate is intentionally simple: all three primary components must have
at least 50% gene coverage. Coverage for the additional confounder/diagnostic
modules is reported but is not used as a hard failure by this precheck.

## Outputs

The precheck writes:

- `primary_module_coverage.tsv`
- `all_module_coverage.tsv`
- `module_coverage_precheck_summary.json`

The summary includes explicit guardrail fields:

- `scores_computed: false`
- `outcomes_read: false`

## Interpretation

A `PASS` means the received expression matrix appears module-scoreable enough to
continue to the full preregistered harness. It is not evidence of biological
signal and does not imply that sample maps, outcome labels, batch metadata, or
terms-of-use gates are complete.

A `FAIL_PRIMARY_MODULE_COVERAGE` means the full response-validation harness
should not be run until the gene identifier mapping or processed expression
matrix is repaired under the preregistered ingestion rules.
