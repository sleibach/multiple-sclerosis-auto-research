# Therapeutic Skeptic Rebuttal Checklist V52

Date: 2026-07-10

Status: synthesis only. This document adds no evidence, changes no verdict, and
does not reopen discovery. It pre-answers the strongest skeptical objections to
the V52 therapeutic-path conclusion.

## V52 Claim Under Review

The defensible near-term MS impact route is validation of the bounded APC/HLA-II
early treatment-response monitoring / stratification signal. No current genetics
lead is intervention-grade. Structure and restored OpenGWAS sharpen the
closures; they do not rescue a target.

## Phrases To Use

- "monitoring / stratification is the near-term impact route"
- "no intervention-grade target is currently supported"
- "structure sharpens feasibility context but does not rescue direction"
- "restored OpenGWAS permits bounded reruns, not renewed discovery"
- "immune-tone bounded monitoring signal"
- "chr1 is a controlled-data target handoff"

## Phrases To Avoid

- "validated clinical biomarker"
- "curative target"
- "GPR25 is druggable because GPCR"
- "KIF21B is targetable because motor-domain structure"
- "PTGER4 is rescued by receptor tractability"
- "OpenGWAS renewal reopens discovery"
- "external context validates the scalar"

## What Would Change The V52 Verdict

| verdict area | evidence that could change it |
|---|---|
| Monitoring route | Frozen V42/V44 validation pass, fail, or immune-tone-bounded result in a complete external cohort |
| chr1 target route | Genotype-linked immune/CSF data resolving causal gene, cell state, protective direction, and direction-matched perturbation |
| GPR25 | Protective haplotype raises/restores GPR25 in a relevant cell state and agonism/restoration perturbation is protective |
| KIF21B | Protective direction is restoration/up-function and a feasible restoration modality produces protective phenotype |
| PTGER4 | Signal-specific MS-protective direction with safe EP4 modulation route |
| ZMIZ1 | MS-specific direction plus perturbation and modality, despite cross-disease warning |

Until one of those arrives, the V52 conclusion remains: validate monitoring
first; do not promote a target.
