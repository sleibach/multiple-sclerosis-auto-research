# Learning Path: Four Ways A Good Story Can Outrun Its Evidence

These four cases teach the reasoning patterns a contributor needs before
proposing a research direction. Each began with a plausible interpretation.
Each became more useful when the project asked what the design could actually
identify.

This is a reading guide to existing results. It adds no scientific claim.

## Case 1: A Contrast Can Be Real And Still Misassigned

### Read

[When a brain-bank pattern changed meaning](CASE_STUDY_BRAIN_BANK_CONFOUND.md)

### Initial Story

A `CD44`/`CXCR4`-high microglial state looked associated with MS.

### Harder Question

Did diagnosis differ from controls within comparable sources, or did diagnosis
and brain bank travel together?

### Honest Result

One discovery partition was strongly source-sensitive. Other bounded support
remained, so the result narrowed to a quality-qualified state association that
requires source-balanced donor replication. It did not become progression,
causal, localization, or target evidence. `[C01-C02]`

### Reflection

1. Which labels could be proxies for the same acquisition process?
2. Does every source contain both outcome groups?
3. What can adjustment estimate when overlap is sparse?
4. Which part of the claim survives if one partition is source-sensitive?

**Reusable lesson:** inspect the design matrix before interpreting the
biological contrast.

## Case 2: A Real Region Is Not Yet A Target

### Read

[When attractive genetics leads reversed](CASE_STUDY_GENETICS_REVERSALS.md)

### Initial Story

GPR25 and PTGER4 looked attractive because they sat in autoimmune-disease
regions and belonged to familiar receptor classes.

### Harder Question

Which signal, gene, cell state, protective direction, and modality form one
coherent intervention chain?

### Honest Result

GPR25 lost protected-favorite status when allele alignment changed the needed
direction and denser immune-QTL evidence favored local alternatives. PTGER4
closed as a naive transfer target when separate components implied conflicting
disease directions. The regions retained bounded biological relevance.
`[G03-G05]`

### Reflection

1. What evidence chooses the causal gene over neighboring genes?
2. Does the protective allele imply more function or less?
3. Can the proposed modality create that direction?
4. Would the region remain interesting if the target route closed?

**Reusable lesson:** separate association, causal entity, direction, and
modality. A familiar protein class supplies none of those links by itself.

## Case 3: An Observer Is Not A Control Point

### Read

[A useful monitor is not a drug target](CASE_STUDY_MONITOR_VS_TARGET.md)

### Initial Story

An early APC/HLA-II change score was associated with later treatment response
in bounded data.

### Harder Question

Does a predictive readout identify a causal node that should be changed?

### Honest Result

One provisional, immune-tone-bounded early-treatment monitor remains. It is
mixed across contexts and awaits outside validation. It does not identify a
baseline selector, mechanism, target, benefit, or progression state.
`[M01-M05]`

### Reflection

1. Is the readout measured before treatment, after treatment, or after outcome?
2. What decision could use it if it validates?
3. Which separate evidence would identify a causal control point?
4. What would a clean external pass still not establish?

**Reusable lesson:** a gauge may be clinically useful without being the knob
that changes the system.

## Case 4: A Snapshot Cannot Identify A Trajectory

### Read

[A snapshot cannot show a progression movie](CASE_STUDY_PROGRESSION_SNAPSHOT_VS_MOVIE.md)

### Initial Story

Progressive subtype, lesion morphology, repeated expression, or a microglial
state looked progression-relevant.

### Harder Question

Was molecular state measured before later disability accumulated and remained
confirmed in the same people?

### Honest Result

The required longitudinal molecular-to-confirmed-disability design is absent.
No progression predictor, transition, mechanism, target, treatment effect, or
halt strategy was established. Existing snapshots and partial roles remain
useful only for their bounded questions. `[B02, P01-P06]`

### Reflection

1. What is measured first and what occurs later?
2. How is disability change confirmed?
3. Which proxy outcome is being mistaken for progression?
4. Can a method repair a missing time order or linked outcome?

**Reusable lesson:** match the data identity to the verb in the claim. A
trajectory verb requires trajectory data.

## The Four Corrections Together

| tempting shortcut | missing distinction | corrected question |
|---|---|---|
| Group difference means disease biology. | Outcome versus acquisition source. | Does the effect exist within comparable sources and donors? |
| Associated region means drug target. | Region versus gene versus direction versus modality. | Which complete intervention chain survives? |
| Predictive readout means causal control point. | Observation versus intervention. | What separate perturbation evidence identifies the control point? |
| Stage or lesion snapshot means progression. | Cross-section versus longitudinal confirmed change. | Was molecular state measured before later confirmed disability? |

All four errors collapse different evidence roles into one attractive story.
The correction is not “be less creative.” It is “make the inference explicit
enough to test.”

## Turn The Lesson Into An Idea

Pick one open problem and complete these sentences:

```text
The project currently cannot distinguish ___ from ___.
My proposed data or method creates the comparison by ___.
The precommitted prediction is ___.
The strongest competing explanation is ___.
The null or holdout is ___.
I would drop or narrow the idea if ___.
This would change the decision from ___ to ___; it would not establish ___.
```

- [the idea triage rubric](IDEA_TRIAGE_RUBRIC.md); and

## Completion Check

You are ready to contribute a direction when you can explain, without looking:

1. why the live lead is a monitor rather than a target;
2. why a real genetic region can remain closed therapeutically;
3. why source overlap must be designed rather than assumed; and
4. why progression needs repeated molecular and confirmed-disability data.

If any answer still feels vague, return to that case. The goal is not to learn
all of MS biology. It is to preserve the project's inference boundaries while
bringing a genuinely different way of thinking to the open problem.
