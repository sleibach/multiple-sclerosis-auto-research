# Your First Research-Direction Idea In Ten Minutes

This exercise turns one outsider observation into a small, reviewable test
card. It does not ask you to solve MS, name a target, or sound medically
expert. It asks you to make one distinction testable.

Set a ten-minute timer. Stop at the end with a draft, not a conclusion. Your
idea has no finding status until suitable data and a valid run support it.
`[E01-E03]`

## Minute 0-1: Choose One Boundary

Circle one:

- `A` The provisional monitoring signal needs a fair outside test.
- `B` The right validation data are hard to access or arrive in messy forms.
- `C` Progression needs repeated molecular and confirmed-disability data.
- `D` A genetics route needs restoration or increased function rather than
  easy inhibition.
- `E` A coupled biological pattern lacks identified control points.
- `F` Source, processing batch, or broad immune state may imitate specificity.
- `G` The same-corpus discovery search reached a boundary.
- `H` A monitor needs a safe decision pathway without becoming a target claim.
  `[M01-M05, G03-G05, D01-D05, P01-P06, C02, A01-A04]`

Write:

```text
I am working on boundary: ____
```

## Minute 1-2: Name An Observation, Not A Solution

Use something your field notices:

- “This looks like a domain-shift problem.”
- “The system may need an abstain state.”
- “A repeated measure is being treated like a static label.”
- “The proposed intervention sign and the available modality do not match.”
- “The two apparent datasets may reuse the same independent units.”
- “A hidden source variable could predict the label.”

Avoid “therefore use my favorite method.” First state the failure or missing
distinction.

```text
My observation is: ________________________________________________
```

## Minute 2-3: Turn It Into One Bounded Question

Use this form:

> In **[specified data and population]**, can **[measurement or method]**
> distinguish **[claim]** from **[main rival explanation]**?

Examples of useful distinctions:

- score-specific signal versus broad immune tone;
- diagnosis versus sample source;
- within-person change versus between-person difference;
- progression versus static stage or relapse;
- controller versus co-moving readout;
- restored function versus inhibited function;
- transport to a new cohort versus refitting the original labels.

```text
My bounded question is: ___________________________________________
```

## Minute 3-4: Make A Directional Prediction

Write what should differ, increase, decrease, persist, disappear, transport,
or fail. “There will be an association” is too vague.

```text
If my idea is right, then _________________________________________
relative to ______________________________________________________.
```

Do not invent a numerical threshold. If no threshold is already frozen, state
the direction and say how a development threshold would later be separated
from its untouched test.

## Minute 4-5: Name The Minimum Data

Specify the independent unit and fields, not only a repository or paper title.

```text
Independent unit: person / donor / site / cohort / data type / other: ____
Required measurements: ___________________________________________
Required times: __________________________________________________
Required outcome or label: _______________________________________
Required source, batch, treatment, and quality fields: ___________
Permission or access requirement: ________________________________
```

For monitoring validation, paired samples without verified response labels are
not enough. For progression, a static stage or relapse label cannot replace
repeated confirmed disability. `[A01-A04, B02, P01-P05]`

## Minute 5-6: Design The Fair Challenge

Choose at least one:

- a fair comparator;
- a null model that preserves the relevant structure;
- a negative control;
- an untouched person, donor, site, cohort, or data type;
- an alternative explanation entered into the same model;
- a source-overlap check that can stop interpretation.

```text
The main rival explanation is: ___________________________________
I will challenge it with: ________________________________________
```

The challenge must be capable of making the attractive interpretation weaker.
A test designed only to confirm it is incomplete.

## Minute 6-7: Add Two Fail-Closed Checks

Pick the two most dangerous errors:

```text
[ ] sample source aligns with outcome
[ ] processing batch aligns with outcome
[ ] repeated samples or donors treated as independent
[ ] treatment or timing leaks the label
[ ] broad immune state or cell composition explains the score
[ ] genes, tissue, or compartment do not match the claim
[ ] several tests are tried without correction
[ ] development and validation data are mixed
[ ] permitted use does not cover the analysis
```

```text
If check 1 fails, the result status becomes: ______________________
If check 2 fails, the result status becomes: ______________________
```

Use “invalid,” “not identifiable,” or “data-blocked” when appropriate. Those
are not biological nulls. `[M04, C02, E01]`

## Minute 7-8: Write The Drop Or Narrow Rule

This is the most important line:

```text
I will drop or narrow the idea if _________________________________
because that result would support ________________________________
instead.
```

Examples:

- the effect disappears under source-balanced overlap;
- the untouched cohort estimate is incompatible with the claimed direction;
- the required restoration cannot be produced in the relevant cell state;
- a simpler baseline performs equivalently under the same held-out unit;
- the required data fields cannot identify the outcome.

Do not rescue a failed idea by changing the outcome, threshold, genes,
exclusions, or primary interpretation after the result.

## Minute 8-9: Check For A Known Non-Solution

Search the [known non-solutions index](KNOWN_NON_SOLUTIONS.md). Answer:

```text
Nearest prior route: _____________________________________________
Its documented failure was: _____________________________________
The assumption or evidence my proposal changes is: ______________
```

If the last line is blank, the idea is probably a duplicate. That is useful to
learn before running anything.

## Minute 9-10: State The Decision It Changes

Choose one honest decision:

- run the frozen outside validation;
- request a named missing data field or cohort;
- advance to a distinct perturbation test;
- retain a bounded monitoring interpretation;
- narrow or close a route;
- improve a method or diagnostic without making a biological claim; or
- do not spend more on this route.

```text
If the result supports the prediction, the project should: _______
If it does not, the project should: ______________________________
If it is inconclusive, the project should report: _______________
```

## Your Ten-Minute Test Card

Copy the completed lines into this compact form:

```markdown
### Boundary
<one boundary letter from the list above and one sentence>

### Observation
<the missing distinction, not a preferred solution>

### Bounded question and directional prediction
<one question; one if/then prediction>

### Data and independent unit
<fields, times, outcome, source, permissions, independent unit>

### Rival explanation and fair challenge
<alternative; comparator/null/holdout/control>

### Fail-closed checks
<two checks and their invalid/data-blocked consequences>

### Drop or narrow rule
<precommitted result and interpretation>

### Prior route changed
<link; exact new assumption or evidence>

### Decision
<what support, failure, and inconclusive results each change>
```

## Self-Check Before Submission

Your draft is ready for triage if every answer is yes:

- Is it one bounded question?
- Can the result be wrong?
- Is the independent unit named?
- Is the main rival explanation tested rather than mentioned?
- Are the minimum data and permissions specified?
- Is there a drop or narrow rule?
- Does it change a documented assumption rather than repeat a shortcut?
- Does it avoid turning monitoring, structure, outside context, or model output
  into causal evidence?
- Is the requested project decision proportional to the test?

If one answer is no, the idea is not rejected; it needs design repair. Use the
[question starters](QUESTION_STARTERS_BY_DISCIPLINE.md),
[worked transformations](IDEA_TRANSFORMATIONS.md), or
[contribution guide](HOW_TO_CONTRIBUTE_IDEAS.md).

## Final Boundary

Ten minutes can produce a clear proposal. It cannot produce biological
evidence, validate a monitor, establish a target, or solve progression. The
value is a test card the project can review without guessing what you meant.
