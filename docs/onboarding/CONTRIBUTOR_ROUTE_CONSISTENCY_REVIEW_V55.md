# Contributor Route Consistency Review V55

This communication audit checks the four specialized contribution routes. It
does not assess a proposal, establish scientific evidence, or change a project
finding. `[E01-E03]`

## Minimum Route Contract

Each guide must let a contributor reach:

1. a worked example for that contribution type;
2. the patient/public and private-data safety boundary;
3. the live research-direction form or the documented pull-request route; and
4. review outcomes that keep workflow status separate from evidence status.

## Result

Current result: `PASS`.

| specialized route | worked example | safety boundary | submission action | review outcomes |
|---|---|---|---|---|
| Data source | contribution examples by type | patient/public safety | live issue form | lifecycle + response templates |
| Method | contribution examples by type | patient/public safety | live issue form | explicit outcome list + response templates |
| Documentation or visual | contribution examples by type | patient/public safety | live issue form or root pull-request guide | response templates |
| Adversarial challenge | contribution examples by type | patient/public safety | live issue form | lifecycle + response templates |

The guides retain route-specific content rather than copying a generic intake
page. Data submissions must verify structure and access; methods must define a
fair test; communication changes must preserve claim status; challenges must
name a discriminating countertest. The shared exits only make delivery and
review predictable.

## Limits

- A complete route does not make a submission valid, novel, or supported.
- The live form requires a GitHub account; a contributor can still draft with
  the [copy-ready idea template](HOW_TO_CONTRIBUTE_IDEAS.md#copy-ready-idea-template).
- Link checks do not prove that a newcomer understands the instructions.
- No V55 human comprehension pilot has run.

Choose a route from the [onboarding landing page](README.md), inspect
[contribution examples](CONTRIBUTION_EXAMPLES_BY_TYPE.md), or review the
[issue-form field guide](ISSUE_FORM_FIELD_GUIDE_V55.md).
