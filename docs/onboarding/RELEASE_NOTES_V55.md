# V55 Public Onboarding Release Notes

V55 makes the project's research frontier understandable and contributable for
smart readers without a medical background. It is a communication release. It
creates **no new scientific claim**, changes no evidence grade, and alters no
locked rule or preregistration.

## The Scientific State Did Not Change

The short honest state remains:

- One fixed APC/HLA-II early-treatment monitoring research lead has internal
  support in 19 participants and awaits an independent test. It is not a
  clinical biomarker, treatment selector, target, cure, or progression measure.
  `[M01-M05, A01]`
- The project has supported biological context, useful decouplings, and
  decision-relevant negative results, but no intervention-grade target.
  `[D01-D05, G01-G05]`
- No progression biomarker, mechanism, target, treatment effect, or means of
  halting progression is established by the held corpus. The key missing object
  is a longitudinal molecular-to-repeated-confirmed-disability design.
  `[P01-P06]`
- Broad same-corpus discovery is bounded under the V41 gate; targeted outside
  validation and genuinely new data remain meaningful. `[D03-D05]`

  clone verification; and

  structure, browser, responsive, print, and manifest checks.

## Integrity Checks

The release includes machine checks for:

- claim IDs, controlling source paths, and forbidden status markers;
- local links and heading anchors;
- plain-language thresholds and undefined acronyms;
- claim/source coverage and high-value route depth;
- root reachability, inbound/outbound navigation, and return-to-start paths;
- heading hierarchy and Markdown table structure;
- semantic SVG names, contrast, non-color status cues, and file size;
- a self-contained text/vector package budget with no large or embedded media;
- browser rendering, constrained-width delivery, and one-page print output;
- provenance segregation and structural-prediction segregation; and
- authored-artifact identity, tracked `tmp/` paths, and large files.

At this release point:

- all 33 bounded claim rows are represented across the reader layer;
- all eight SVGs are present with linear text equivalents;
- all 17 configured high-value routes and all 73 public-page connectivity
  records pass;
- 74 checked documents, 1,027 headings, and 112 tables pass 2,291 semantic
  checks; and
- the public package contains 84 lightweight files and remains under 1 MiB.

The public GitHub workflow has passed the full suite on `main`. These are
communication and repository-integrity checks. They do not validate the
science or prove that a person understood the pages.

## Human-Test Status

No human newcomer comprehension session has been completed or claimed.
Claude and Gemini were used early as drafting/comprehension challenge tools;
their output was not a scientific source. A committed facilitator handoff,
scorecard, and idea-production task are ready for a future human pilot.

The next communication test is therefore empirical: can an unaffiliated smart
generalist recover the correct status, reject the key overreads, and produce a
falsifiable test card without coaching?

## What Contributors Should Expect

Submission means **received for review**, not supported. Review checks safety,
scope, duplication, data eligibility, falsifiability, independence, nulls,
confounders, multiplicity, and a drop rule. A proposal can be repaired, parked,
closed as duplicate, made runnable, or refused safely without becoming a
finding.

The central rule remains: ideas choose what to test; eligible data and valid
analysis decide what the project can say. `[E01-E03]`
