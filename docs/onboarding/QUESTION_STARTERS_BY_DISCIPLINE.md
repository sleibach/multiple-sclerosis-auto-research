# Question Starters By Discipline

You do not need medical training to contribute a useful research direction.
You do need to translate your expertise into a prediction the project can test
without changing the evidence rules.

The prompts below are invitations, not hypotheses or findings. They start from
project boundaries already recorded in the source contract. A prompt earns no
scientific status until a real, eligible analysis supports it. `[E01-E03]`

## First Choose The Boundary, Then The Method

Pick one boundary:

1. a small provisional monitoring signal needs a fair outside test;
2. usable validation data are difficult to access;
3. progression lacks repeated molecular-to-disability measurements;
4. some genetic routes require restoration rather than easy inhibition;
5. a coupled immune pattern lacks identified control points;
6. source, batch, and broad immune state can mimic specificity;
7. unconstrained search of the same assembled corpus reached a boundary; or
8. a monitor needs a safe decision pathway without being called a target.
   `[M01-M05, G02-G05, D01-D05, P01-P06, C02, A01-A04]`

Then ask: **What does my discipline let us distinguish that the current design
cannot distinguish?**

## Statistics And Causal Inference

Useful starters:

- Can we report the small validation cohort in a way that cleanly separates
  effect estimation, decision thresholds, and inconclusive uncertainty?
- Which sensitivity analysis would distinguish a specific monitoring
  association from broad immune tone without tuning the locked score?
- What overlap diagnostic should make a source-adjusted comparison stop rather
  than extrapolate?
- Can a partial-identification bound say something honest when progression
  timing or attendance is incomplete?
- Which unit must be held out: sample, person, donor, site, cohort, or data type?
- How should several genuinely comparable small cohorts be combined without
  pretending that two analyses of the same people are independent?

Make it useful by naming the estimand, independent unit, null, uncertainty
interval, multiplicity family, and failure condition. Do not propose a new
threshold after seeing the outcome. `[M03-M04, A01, A03, C02]`

## Software, Data, And Metadata Engineering

Useful starters:

- Can a schema prove that sample IDs, people, baseline/early times, labels, and
  module genes map correctly before the harness sees an outcome?
- Which inconsistencies in a returned package should force refusal rather than
  silent repair?
- Can repository metadata expose that two apparently separate cohorts reuse
  donors or source material?
- How can we fingerprint a frozen rule, input package, and result so a later
  reader can reproduce exactly what ran?
- Can a search tool match near-miss datasets to the exact missing eligibility
  fields instead of returning a list of titles?
- What minimal holder-side execution bundle allows a legally restricted cohort
  to run the test without releasing individual-level data?

Make it useful with a machine-readable input/output contract, synthetic pass
and fail fixtures, and a refusal state. Do not count a cohort as usable until
pairing, labels, genes, provenance, and permitted use are verified. `[A01,
A02, A04]`

## Privacy, Security, And Federated Collaboration

Useful starters:

- What is the smallest sufficient return package for the frozen monitoring
  test if raw data cannot leave the holder?
- Can the holder prove which code, rule version, and exclusions ran without
  disclosing participant records?
- Which aggregate outputs would accidentally permit re-identification in a
  tiny cohort?
- How should a package fail closed when use terms do not authorize the planned
  analysis?
- Can a multi-site progression design preserve person-level longitudinal
  linkage while minimizing exchanged fields?

Make it useful by stating the threat model, permitted operations, privacy unit,
audit evidence, and conditions requiring human approval. Privacy protection
cannot compensate for missing outcomes or an unidentifiable design. `[A01-A04]`

## Control Theory And Dynamical Systems

Useful starters:

- What perturbation pattern would distinguish a controller from a readout in
  the coupled APC architecture?
- Which observations would separate feed-forward response, feedback, and a
  shared hidden driver?
- Can restoration-direction intervention be framed as state recovery rather
  than default inhibition?
- What intervention sequence would distinguish redundancy from synergy without
  promoting every co-moving node?
- Which longitudinal sampling times are needed to distinguish a transient
  immune response from a state change that precedes disability?

Make it useful with competing system diagrams, intervention signs, observable
predictions, and one experiment that selects among them. Co-movement alone does
not supply edges, control, or a multi-node treatment. `[D01-D02, G03-G05,
P01-P03]`

## Machine Learning And Artificial Intelligence

Useful starters:

- Can a model detect domain shift or source-label entanglement before fitting a
  biological contrast?
- What representation is fixed before validation, and what independent unit
  tests transport rather than memorization?
- Can a method abstain when a sample lies outside the training support?
- Which negative-control task would expose leakage from treatment, site,
  processing batch, or repeated donors?
- Can active learning identify the single new measurement that most reduces
  uncertainty in a progression design?
- Can a language model turn a broad suggestion into alternative falsifiable
  test cards without scoring its own output as evidence?

Make it useful with a frozen development/validation split, leakage audit,
baseline comparison, calibration, abstention rule, and multiplicity plan. A
more flexible fit on the same small labels and agreement among models are known
non-solutions. `[M03, D02-D05, E03, C02]`

## Human Factors, Design, And Decision Science

Useful starters:

- What decision could an independently validated early monitor actually
  support, and what decision must it never imply?
- How should a user interface display pass, fail, inconclusive, unscoreable,
  and confound-attenuated outcomes without nudging users toward confirmation?
- Which workflow makes abstention safer than a forced prediction?
- What false-positive and false-negative harms matter before a score influences
  any clinical workflow?
- Can contributors see the difference between “runnable,” “supported,” and
  “validated” without reading the whole repository?
- What comprehension test reveals whether a visual silently turns monitoring
  into treatment selection or progression prediction?

Make it useful by defining the user, decision, permitted claim, error costs,
abstention behavior, and next evidence gate. A polished interface cannot create
clinical utility or therapeutic evidence. `[M01, M05, A01, E01]`

## Measurement Science And Experimental Design

Useful starters:

- Which repeated molecular and disability measurements are essential, and
  which merely add detail, for a progression study?
- How should timing be chosen so the molecular measurement precedes rather than
  follows the outcome it is meant to predict?
- What source-balanced sampling design prevents diagnosis from identifying the
  tissue bank or acquisition process?
- Which direction-resolved assay could distinguish increased from decreased
  function in a candidate cell state?
- What orthogonal measurement would challenge a gene-expression module rather
  than reproduce the same measurement technology?
- When does measurement error make an apparently negative result
  non-identifiable rather than negative-established?

Make it useful with the unit, timing, assay, calibration, source strata,
blinding, and precommitted exclusion rules. A static stage label, lesion image,
relapse outcome, or blood score cannot silently substitute for the required
longitudinal compartment. `[B02, G03-G05, P01-P06, C02, A02]`

## Operations Research And Resource Allocation

Useful starters:

- Given a high chance that a small cohort is inconclusive, which next data
  acquisition has the highest expected information value?
- When should the project request labels, run a federated test, seek a second
  cohort, or stop investing in a route?
- Can a portfolio design reduce dependence on one politically or legally
  constrained dataset without weakening eligibility?
- Which test retires the most assumptions per unit of laboratory or access
  effort?
- How should closed routes remain searchable so they prevent duplicated work
  without suppressing genuinely new reopening evidence?

Make it useful with explicit decisions, costs, probabilities or bounds, and the
observation that would change the ranking. Do not turn synthetic planning
assumptions into biological effect estimates. `[A03-A04, D05]`

## Protein Engineering, Chemistry, And Modality Design

Useful starters:

- If protection requires more or restored function, what modality could
  produce that sign in the relevant cell state?
- Which assay would reject a structurally attractive but directionally wrong
  intervention?
- Can delivery or state selectivity be tested before declaring a modality
  feasible?
- What evidence would distinguish a functional interface from a high-confidence
  predicted shape that has no useful intervention path?
- Which gain-of-function, stabilization, replacement, or targeted-delivery
  concept has a measurable falsification readout?

Make it useful by naming the causal entity, required sign, target cell/state,
modality, delivery assumption, assay, and stop rule. A pocket, known ligand, or
protein-family precedent cannot repair unresolved causal genetics. `[G02-G05,
E01-E02]`

## Researchers From Other Diseases Or Fields

Useful starters:

- Which result from your field depends on a design feature this project lacks,
  and can that feature be transferred without transferring the conclusion?
- What failure mode does your discipline routinely test that this project may
  not name?
- Is there a dataset with the required people, times, outcomes, compartment,
  and provenance rather than merely similar biology?
- What rival explanation would your field demand before interpreting one of
  the project's bounded associations?
- Which method imported from your field has a clear null and an independent
  validation unit here?

Make it useful by separating analogy from equivalence. State the outside
source, the project prediction it motivates, and the real data that could
reject it. Outside agreement or novelty remains context until grounded. `[E01-
E03]`

## Turn One Starter Into A Submission

Complete these sentences:

```markdown
Boundary I address:
The distinction my discipline can test is:
My directional prediction is:
The required data and independent unit are:
The main alternative explanation is:
The null, negative control, or fair comparator is:
The result that would make me drop or narrow the idea is:
The prior shortcut I am not repeating is:
The project decision this result would change is:
```

Then check the [known non-solutions](KNOWN_NON_SOLUTIONS.md), choose the
matching [open problem](OPEN_PROBLEMS_FOR_COLLABORATORS.md), and use the
[ten-minute idea exercise](FIRST_IDEA_IN_TEN_MINUTES.md) or the full
[contribution guide](HOW_TO_CONTRIBUTE_IDEAS.md).

## Important Limit

Expertise can improve the question, design, implementation, or interpretation.
It does not transfer authority across disciplines. The proposal remains a
proposal until suitable data and a valid run produce an eligible result.
