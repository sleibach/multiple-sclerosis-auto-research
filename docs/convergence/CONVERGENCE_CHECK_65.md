# Convergence Check 65

Timestamp: 2026-05-28 06:41 CEST

## Current Question

After closing CD82, MFGE8, GPR183, PSAP, and P2RX7 as therapeutic-discovery
branches, is there still a defensible route inside the lipid-lysosomal myeloid
module that can satisfy the V3 DoD?

## Track Status

### Closed or Parked

- `CD82`: robust niche biomarker signal, but multiplicity and prior-art audits
  collapse it to a provisional readout, not a target.
- `MFGE8`: simulation provides an assay constraint, but no strict theoretical
  safety window.
- `GPR183`: receptor/ligand compartment coherence fails in fallback test.
- `PSAP`: weak single-context marker; no myeloid recurrence and no perturbation
  support.
- `P2RX7`: target-level stratification closure audit fails all reopening gates.

### Active Forcing Need

The next line must avoid proxy-satisficing. It should test whether a candidate
behaves as a controller after residualizing generic IFN/APC, NF-kB/TNF,
lysosome/APC, and tissue activation, and it should require direct perturbation
or modality evidence before promotion.

## Decision

Proceed to a remaining route only as a falsification-first controller test.
`SPNS1` is the obvious next biology-control branch from prior sidecars because
it is mechanistically close to lysosomal lipid egress and relatively novelty
clean, but prior notes already warn that it lacks chemical matter, MS anchor,
and clear intervention direction. The forcing question is therefore narrow:
does `SPNS1` retain downstream lipid/APC-state coupling after confounder
residualization in at least two diseases and show any treatment-response or
perturbation support? If not, close it without therapeutic promotion.
