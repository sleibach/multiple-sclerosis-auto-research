`LILRB2` directionality is the forcing question:

- If simulated `LILRB2` deletion in non-remission myeloid/DC cells moves cells
  toward the remission centroid, `LILRB2` suppression becomes a plausible but
  still weak intervention branch.
- If deletion moves cells away from remission, high `LILRB2` is more likely a
  compensatory brake, and the branch should pivot to agonism/restoration or be
  parked if druggability/prior art blocks that route.
- If the model cannot support enough `LILRB2` token-bearing cells, the local
  data cannot answer the directionality question and this branch should not be
  promoted.

inhibitory receptors, inhibitory phosphatases, TAM resolution nodes, and
blocked comparator controls.

Promotion criterion is deliberately strict: at least one less-blocked candidate
must show consistent model movement toward remission in multiple contexts, with
usable token support, and with sidecar prior-art/translational audit not
identifying a blocking problem.
