# Convergence Check 8: Target-Resolved Causality Gap

Date: 2026-05-27 07:07 UTC

## Trigger

Wave23 hostile critique identified the most important unresolved route:
target-resolved causal genetics to module state. A mapped-gene or broad
OpenTargets locus score is not enough for the V3 DoD.

  `subagents_v3/wave23_metabolite_barrier_circuit.md`
- Wave25 proxy audit:
  `scripts/v3_wave25_causal_genetics_module_proxy.py`

## What Each Track Now Believes

- Metabolite/barrier track: no actionable route. AHR/tryptophan is the closest
  biology but lacks strict residual, genetic, and L1000 support. FXR/TGR5 is
  least crowded but locally unsupported.
- Genetics-to-module track: no target-resolved causal claim is available. The
  GWAS Catalog parquet is readable, but it is top-association schema and not
  coloc-sufficient.
- Restoration genetics track: `PTPN2` is the only candidate with enough breadth
  to be worth future coloc, but it is explicitly `COLOC_NEEDED_NOT_CLAIMABLE`
  and remains blocked by TCPTP restoration modality.
- Module-marker track: several genes replicate as cell-state markers, but
  without genetic anchoring they cannot be promoted as causal intervention
  points.
- Perturbation track: recurrent L1000 reversal did not reveal a non-generic
  repurposing candidate.

## Agreement

All active tracks now agree on the same constraint: the shared
lipid-lysosomal/APC module is real enough as a cross-disease state, but no
single target currently connects genetic causality, correct-direction
perturbation, and tractable intervention.

## Disagreement

`PTPN2` remains biologically attractive under breadth/genetics, but the
therapeutic direction is restoration rather than inhibition. `GPR65` remains
druggable and genetically suggestive, but local module evidence is weak and
prior art is direct. Neither disagreement is sufficient to support a finding.

## Decision

Do not promote any genetics-first target. Treat `PTPN2` as a future
fine-mapping/TCPTP-restoration work item only. The session remains below the
twelve active-hour floor, so the next step is another pivot, not exhaustion.

## Next Forcing Question

Can a response-labeled clinical dataset or a real perturbation dataset supply a
more direct intervention point than the genetics proxy route? Candidate
directions:

1. Re-open treatment-response stratification only if two independent datasets
   support baseline prediction or a mechanistically coherent pharmacodynamic
   readout.
2. Search real perturbation datasets for non-JAK/non-steroid interventions that
   suppress the module with selectivity.
3. Deconvolve unknown recurring L1000 BRD compounds only if a target/MOA can be
   assigned without speculative chemistry.
