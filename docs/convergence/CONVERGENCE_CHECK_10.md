# Convergence Check 10: Target-First Rescue After Module-First Failures

Timestamp: 2026-05-27 07:26 UTC

## Forcing Question

If the lipid-lysosomal/APC module is a real shared autoimmune state, can a
target-first search recover a druggable intervention point that reconnects to
the module through independent evidence?

## Inputs

- Wave25 target-resolved genetics-to-module proxy audit.
- Wave26 strict treatment-response audit.
- Wave27 L1000 unknown-BRD deconvolution.
- Wave28 target-first rescue audit.
- Prior Wave20/Wave21 target-first and residual-druggability outputs.

## Agreement Across Tracks

- Cell-state evidence exists across diseases, but it is still easier to find
  markers than causal controllers.
- The strongest broad genetics comparators (`PTPN2`, `TNFAIP3`, `SH2B3`,
  `IRF5`, `GPR65`) are not claimable without target-resolved causal evidence,
  correct directionality, and a feasible modality.
- The strongest druggable targets (`BTK`, `TYK2`, `IL6R`, `RIPK1`, `NLRP3`,
  `IRAK4`, `SYK`, `PDE4B/D`, `CTSS`) are either prior-art saturated,
  generic immune suppression, or not locally tied to the module.
- `SQLE` is the only target-first park after Wave28, but it is an
  IBD/stromal-residual branch without target-level genetics or perturbation.

## Disagreement Or Tension

- `PTPN2` has the best genetics/module plausibility but the wrong available
  pharmacology: inhibitors exist, while autoimmunity would require restoration
  or activation.
- `SQLE` has practical druggability and residual signal but lacks the causal
  anchors that would make it more than a disease-state marker.
- L1000 reversal finds compounds, but target/MOA deconvolution collapses toward
  cytotoxic, steroid, prostanoid, or pleiotropic chemistry.

## Decision

No therapeutic-relevant V3 claim is ready.

The next productive route should not be another expression or broad
druggability screen. The live options are:

1. Build a mechanistic/simulation branch around `PTPN2` restoration to quantify
   whether feasible partial restoration would move the module without generic
   immunosuppression, while acknowledging no current modality.
2. Search for actual perturbation datasets around `SQLE`/sterol metabolism in
   stromal/myeloid autoimmune contexts; abandon if perturbation does not reverse
   the module.
3. Use a different modality not yet exhausted: cell-cell ligand/receptor
   modeling from spatial/single-cell data to find a non-marker upstream driver
   of the module.

Active-time accounting remains below the twelve-hour floor, so the run
continues.
