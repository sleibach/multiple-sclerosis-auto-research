# V57 Cross-Method Data-Unlock Portfolio: Frozen Plan

Status: **frozen before portfolio results**

## Question

Which data package, or small portfolio of packages, unlocks the largest amount
of decision-relevant analysis that the project has not yet been able to run
properly?

This differs from the V54 progression acquisition ranking. V54 specifies the
fields needed for a progression cohort. This analysis compares several types
of prospective data across the whole current method frontier. It does not
estimate the probability that any package will reveal useful MS biology.

## Inputs

Eight package specifications are defined from current, committed blockers:

1. an independent paired MS treatment-response bulk cohort;
2. a paired, response-labelled MS single-cell trajectory cohort;
3. longitudinal molecular-to-confirmed-disability MS data;
4. randomized progression-trial participant-level data;
5. a randomized molecular progression substudy;
6. direction-resolved primary-human perturbation data;
7. replicated chronic-active-lesion spatial data; and
8. genotype-linked immune state and perturbation data.

Each package has an ordinal acquisition-burden range, required fields, blocked
methods it unlocks, and supporting repository artifacts. Burden units are
relative planning labels, not money or access probabilities.

## Fixed Evaluation

Enumerate every one-, two-, and three-package portfolio. For each portfolio:

- count unique methods unlocked;
- count distinct decisions unlocked;
- sum scores under six fixed priority views: equal, validation-first,
  progression-first, causal-treatment-first, mechanism-first, and
  feasibility-first;
- compute minimum and maximum ordinal burden; and
- identify portfolios not dominated on method coverage, decision coverage,
  scenario score, and burden.

Report rank stability across scenarios. A package is a robust first ask only if
it ranks first in at least four of six scenarios and is on the one-package
Pareto frontier. Otherwise report the competing frontier rather than forcing a
winner.

## Boundaries

- The analysis is decision support, not biological evidence.
- Scenario weights encode priorities, not expected scientific effects.
- The result cannot make an unavailable or access-controlled package usable.
- Existing V42/V54 data-quality and identifiability gates still apply after a
  package arrives.
- No quarantined cohort is inspected.
