# chr1 No-Go Communication Appendix V52

Date: 2026-07-10

Status: collaborator-facing wording appendix. This document adds no evidence,
changes no chr1 verdict, and does not reopen GPR25 or KIF21B. It gives safe
language for explaining why chr1 is real biology but not target-ready.

## Short Version

The chr1 KIF21B/GPR25 region remains a real MS-UC shared-biology locus, but it
is not a current MS therapeutic target. The blockers are not lack of interest
or lack of structural plausibility. The blockers are causal-gene ambiguity,
cell-state uncertainty, protective-direction requirements, and absence of a
direction-matched modality.

## What We Can Say

| point | safe wording |
|---|---|
| Biology | "chr1 remains one of the strongest controlled-data handoff regions in the project." |
| Causal gene | "Current public data do not resolve GPR25 versus KIF21B and local alternatives well enough for target promotion." |
| Direction | "The most plausible protective directions require restoration or increased function, not generic inhibition." |
| Structure | "AlphaFold DB context makes tractability discussion more concrete, but it does not resolve causality or therapeutic direction." |
| Next data | "A genotype-linked immune or CSF molecular package could make the locus decision-useful." |

## What We Should Not Say

| unsafe wording | why not |
|---|---|
| "GPR25 is an MS target." | Causal gene, relevant cell state, protective direction, ligand biology, and perturbation are unresolved. |
| "KIF21B is druggable, so it is back on." | Structure does not solve the restoration/up-function direction requirement. |
| "A GPCR is automatically tractable." | The required GPR25 direction is likely agonism/restoration, and chemical matter is immature. |
| "Kinesin inhibitors are a route for KIF21B." | Inhibition/degradation/knockdown is likely wrong-direction unless future data prove otherwise. |
| "The chr1 locus validates a treatment idea." | It is a genetics handoff until causal gene, cell state, direction, and perturbation align. |

## Sendable Collaborator Paragraph

The chr1 KIF21B/GPR25 region is still scientifically important, but we are not
treating it as a current therapeutic target. The region needs a controlled
genotype-linked package before target work is justified: direct or high-quality
imputed chr1 credible-set dosage, ancestry covariates, immune or CSF molecular
readouts for GPR25, KIF21B, C1orf106/INAVA, and local genes, cell-state labels,
and ideally perturbation readouts. The key question is whether the protective
haplotype points to a specific gene in an MS-relevant cell state and whether
moving that gene in the protective direction is feasible. Until that chain is
shown, chr1 remains a strong biology handoff, not a target program.

## Data That Would Move The Locus

| gate | required to move forward |
|---|---|
| Causal gene | one candidate beats GPR25/KIF21B/local alternatives in an MS-relevant cell state |
| Direction | protective haplotype direction is harmonized and points to higher/restored or lower/reduced state explicitly |
| Cell-state relevance | effect is visible in immune, CSF, or CNS-adjacent cells relevant to MS biology |
| Protein or function | RNA signal has protein or functional support where assay permits |
| Perturbation | changing the candidate in the protective direction moves an MS-relevant phenotype |
| Modality | a plausible therapeutic modality implements the protective direction without relying on wrong-direction inhibition or knockdown |

## Lead-Specific Message

| lead | concise message |
|---|---|
| GPR25 | Interesting receptor-like candidate, but not target-ready without genotype-linked evidence that protective biology is higher/restored GPR25 signaling in a relevant cell state and an agonism/restoration route. |
| KIF21B | Serious chr1 candidate, but the likely protective route is restoration/up-function; generic kinesin inhibition, degradation, ASO, or siRNA remains wrong-direction until proven otherwise. |
| C1orf106/INAVA and local alternatives | Must remain in the comparison set; a package that tests only a favorite gene is not sufficient for target promotion. |

## Response To Common Questions

| question | response |
|---|---|
| "Should we start a GPR25 assay?" | Only as part of a genotype-linked package that also measures KIF21B and local alternatives, and only if the assay can test restoration/agonism direction. |
| "Should we screen KIF21B inhibitors?" | Not as a therapeutic route. Inhibition can be used as a wrong-direction control if restoration is the hypothesized protective direction. |
| "Does AlphaFold make either target viable?" | It helps with feasibility context, not disease causality or direction. |
| "What is the cheapest useful next experiment?" | Genotype-stratified immune or CSF single-cell/protein readout around the chr1 haplotype, followed only then by direction-matched perturbation. |
