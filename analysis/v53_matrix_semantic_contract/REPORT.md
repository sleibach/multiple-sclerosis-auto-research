# V53 Matrix Semantic Contract

This artifact freezes the row semantics and permitted analytical capabilities
of six V26 summary matrices before further exploratory use. It is a method
guard, not a biological result.

The real-data audit checks 72 file, schema, hash, key, and contract conditions;
all pass. A synthetic requirement check correctly allows context-level use of
the perturbation summaries and rejects patient-level temporal inference from
aggregate pharmacodynamic rows.

Applied to the V53 Claude/Gemini proposal set, 12 of 16 matrix-dependent
capability requests exceed what the held summaries support and four pass. The
separate AlphaFold-complex proposal is outside these matrices and remains
governed by the structural-prediction gate. A failed capability request means
only that the current matrix cannot test it; it does not count as evidence
against the biological hypothesis.
